# Cake Shop Web Application

A React-based Cake Shop web application developed as a web development project.

## About the Project

This project aims to provide a user-friendly interface for exploring a cake shop website.

## Technologies Used

* React.js
* JavaScript
* HTML
* CSS

## Features

* User-friendly website interface
* Cake shop website pages and components

## Getting Started

### Prerequisites

* Node.js
* npm

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/DhananjanaB/cake-shop-project-new
   ```

2. Navigate to the project folder:

   ```bash
   cd cake-shop-project
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm start
   ```

5. Open http://localhost:3000 in your browser.
